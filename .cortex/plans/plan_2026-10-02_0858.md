## Context

The frontend has ~15 `fetchApi()` calls hitting `localhost:8000` which doesn't exist. The PDM database in Snowflake has all the data needed across `CORE`, `RAW`, and `ANALYTICS` schemas. We need to:

1. Install `snowflake-sdk` in the Next.js project
2. Create a shared Snowflake connection helper for API routes
3. Build Next.js API routes (`app/api/*/route.ts`) for each endpoint
4. Update `lib/api.ts` to call Next.js API routes instead of `localhost:8000`

### Step 3: Create `lib/snowflake.ts` — shared connection helper
A server-side-only module that creates/pools a Snowflake connection and exposes a `query(sql, binds)` function returning rows as JSON.

### Step 4: Update `lib/api.ts`
Change `API_BASE` to empty string (`''`) so `fetchApi('/api/kpis')` hits the Next.js API routes directly instead of `localhost:8000`.

### Step 5: Create 11 API routes (each as `app/api/<name>/route.ts`)

| Route | SQL Source | Returns |
|---|---|---|
| `/api/hero-briefing` | `DIM_SITE`, `DIM_ASSET`, `DT_OEE_LINE_SHIFT`, `OPERATOR_TECHNICIAN_ASSIGNMENTS` | Greeting, factory count, assets, workforce, OEE, plant badges |
| `/api/kpis` | `DT_OEE_LINE_SHIFT`, `FACT_WORK_ORDER`, `CUSTOMER_ORDERS`, `FACT_MACHINE_STATE` | 7 KPI cards (OEE, output, downtime, cost avoidance, alerts, orders at risk) |
| `/api/plants` | `DIM_SITE` joined with `DT_OEE_LINE_SHIFT`, `DIM_ASSET`, `FACT_MACHINE_STATE` | Array of factory health objects |
| `/api/alerts` | `DT_ASSET_FEATURES` joined with `DIM_ASSET`, `CFG_ASSET_THRESHOLDS` | Critical machine alerts (high temp/vibration) |
| `/api/production` | `DT_OEE_LINE_SHIFT` | Daily production performance (8 days) |
| `/api/maintenance/readiness` | `FACT_WORK_ORDER` | Maintenance readiness stats |
| `/api/maintenance/queue` | `FACT_WORK_ORDER` joined with `DIM_ASSET` | Maintenance queue items |
| `/api/technicians` | `OPERATOR_TECHNICIAN_ASSIGNMENTS`, `SKILLS_CERTIFICATIONS` | Technician availability counts |
| `/api/supply-chain/risk` | `PURCHASE_ORDERS` joined with `SUPPLIERS_VENDORS` | Late/at-risk POs |
| `/api/orders` | `CUSTOMER_ORDERS` | Customer orders with risk status |
| `/api/revenue-impact` | `CUSTOMER_ORDERS`, `FACT_WORK_ORDER` | Revenue at risk, delivery risk |
| `/api/energy` | `ELECTRICAL_POWER` grouped by plant | Per-plant energy consumption |
| `/api/activity-stream` | `OPERATOR_ACTIONS_LOGS` | Recent 10 operator events |
| `/api/recommendations` | Derived from alerts + work orders | AI-recommended actions |
